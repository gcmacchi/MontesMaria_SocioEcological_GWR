# MontesMaria_SocioEcological_GWR
Reproducible analysis of socio-ecological drivers of forest change in Montes de María (Colombia). Integrates dasymetric population grids (2005-2018), ERA5 anomalies (1950-2023), and Landsat EVI composites (1999-2003, 2018-2022) in a GWR model. Spatial regime map (H0, H1, H2, H1×H2) for the Applied Geography paper.
